# Notice of a new version

Row `binnacle-notice`. To turn it off, see [Features](index.md#features). To change it, see [its page for authors](../author/built-ins/notice.md).

- When binnacle starts and npm has a newer version, see the notice above the transcript's first event: the new version, the command that installs it, `npm install -g @easeshine/binnacle`, and where its changes are. It scrolls away with the transcript.
- See each version told once. The next start says nothing of it, until a newer one is out.
- Start binnacle after you install the new version, and binnacle installs it into its profile too, as [Install and start](index.md#install-and-start) says.
- Offline, or with the row turned off, see no notice. With the row off, binnacle asks npm nothing.
